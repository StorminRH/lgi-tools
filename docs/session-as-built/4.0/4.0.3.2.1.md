## Delivered outcome

The Atlas canvas moves like water. Arrivals surface in place — small, dim,
swelling through a sampled-spring overshoot to settle sharp — identically on
initial load and live insertion; a `system-moved` landing inside a node's
birth window relocates it instantly so a reveal finishes surfacing at its
tree position. Forced layout shifts glide along the spring through a
state-driven tween scheduler (pure `tween-model.ts` + pure
`motion-host-model.ts` + the thin `use-motion.ts` hook): rendered nodes and
edges derive from reconciled truth plus displacement in the same React
commit, so edges track their endpoints by construction and no
teleport-and-return frame can paint. Departures play clock-bounded ghost
exits (node ghosts inert via inline `pointerEvents`, edge ghosts captured
from a previous-merge edge memory), with edge flavor selectable
(grow-from-parent draws/retracts along the path via pathLength-normalized
stroke-dash; dashed loop edges always fade). Hover is the one
cursor-responsive moment; the idle map registers zero animation frames. The
camera always eases — fits carry slow-tier easing with bounds from
reconciled targets, flights are generation-tracked because superseded
viewport promises never settle, a drag start halts any in-flight pan, and a
new click-focus user setting centers a clicked system at preserved zoom.
Reduced motion collapses glides to instant placement, births/exits to gentle
fades, and camera duration to zero, including live flips. Drag hardening
memoizes nodes, edges, the control panel, and the camera host behind
identity-stable props, holding p50 8.3 ms / p95 ≤ 10 ms dev-mode frame times
at the 50–60 node ceiling. Motion dials (three tempo tiers, overshoot, edge
flavor, collapse weight) join the tuning panel; the G-1 gate ratified
fast 250 / mid 1000 / slow 1000 ms, overshoot 12 %, grow-from-parent,
click-focus ON, and — amended at the same gate after a live heavy preview —
ordinary collapse exits, with heavy kept as a dial keyed to the
wormhole-collapse batch signature.

The gate also drove a write-path correction: chain reveals and collapses are
now single Convex transactions. `placeJumpFixture` records a discovered
system with its discovering connection atomically (one endpoint must already
exist); `collapseJumpFixture` severs a connection with the system it had
discovered, proving map and endpoint pairing and rolling the whole
transaction back on refusal. The replay tool spawns each jump atomically and
tears down newest-first through per-step records, so nodes are born on the
tree and leave with their hole.

## Divergences from plan

- **Plan statement:** the tween scheduler consumes intents with origins from
  the intent's `from`; no birth-window special case.
  **Built instead:** a `system-moved` landing inside a node's entering
  window relocates instantly (no tween), reading the window from the working
  batch so a same-batch birth counts.
  **Why:** the split system/connection subscriptions deliver a reveal's two
  documents in separate merges; the kernel first places the system
  unattached and the subsequent attach glide read as "spawn nowhere, zip
  over."
  **Authority:** Operator: in-session direction at the G-1 loop
  (2026-08-02).
- **Plan statement:** replay and fixtures unchanged; motion consumes
  whatever merges arrive.
  **Built instead:** atomic `placeJumpFixture`/`collapseJumpFixture` and a
  per-step `SpawnRecord` replay restructure; comments bind the production
  auto-mapper (4.0.4.2) to the transaction boundary with upsert semantics.
  **Why:** the root cause of both the reveal zip and the departure
  orphan-then-vanish was the two-transaction write shape, not motion.
  **Authority:** Operator: directed in-session (2026-08-02); Evidence:
  reviews confirmed pairing proof and rollback.
- **Plan statement:** `use-motion.ts` owns the host state machine and
  derivation; `MotionSeams` carries a ref-backed `readDragging`.
  **Built instead:** the pure half lives in `motion-host-model.ts` and the
  hook file exports only `useMotion`/`MotionSeams`/`BROWSER_MOTION_SEAMS`;
  `dragging` is a committed prop with a hook-owned mirror ref for frame
  callbacks; `use-motion.test.ts` (plan-named proof file) drives the model.
  **Why:** the React Compiler lint forbids render-time ref reads, and the
  narrow hook surface keeps a second consumer from opening a second position
  channel (HC-1).
  **Authority:** Evidence: zero-warning lint gate; pre-PR architecture
  review.
- **Plan statement:** `ChainEdgeData`/node data gain motion fields in their
  owning files.
  **Built instead:** the `NodeMotion`/`EdgeMotion`/`MotionPhase` vocabulary
  is owned by `motion-contract.ts` and imported by `SystemNode.tsx` and
  `nodes.ts`.
  **Why:** the vocabulary owner already declared itself; two independent
  copies had begun to drift.
  **Authority:** Evidence: pre-PR ownership/architecture reviews.
- **Plan statement:** PD-3 ships `collapseWeight` decided at the gate; the
  provisional trigger was a multi-system departure batch.
  **Built instead:** heavy triggers on the wormhole-collapse signature — a
  system departing together with a connection in one merge — and the
  shipped default is ordinary.
  **Why:** the atomic collapse emits exactly one system per transition, so
  the multi-system trigger became unreachable dead presentation; the
  operator previewed the re-keyed heavy live and chose ordinary as default.
  **Authority:** Operator: extended-gate direction and amended ratification
  (2026-08-02); Evidence: holistic adversarial review surfaced the dead
  trigger.
- **Plan statement:** ghost non-interactivity via a `.map-ghost` stylesheet
  rule; heavy exits unspecified per surface.
  **Built instead:** ghost snapshots carry inline
  `style: { pointerEvents: 'none' }` (the class remains as DOM witness
  only); heavy grow-retract variants and reduced-motion heavy fades run on
  the slow tier, matching the scheduler's `heavyExitMs`.
  **Why:** React Flow writes its own inline pointer-events (truthy once
  `onNodeClick` is forwarded), which no class rule can beat; the exit
  duration mapping needed one owner across JS and CSS.
  **Authority:** Evidence: pre-PR interface/ownership reviews verified
  against the installed library.

## Discovered work

- The heavy-exit trigger's evolution belongs to the 4.0.4.1 unified collapse
  pathway (recorded in SCRATCHPAD and the `isCollapseBatch` contract
  comment).
- The replay corpus's deferred-edge policy can spawn a system bare with its
  connection one step later (observed live as a transient "orphan"); a
  corpus artifact impossible under jump-driven reveals — documented here,
  no action.
- `useMotion`'s own wiring (render-phase adoption, rAF start/stop, teardown)
  has no mounted unit test, matching the repository's no-client-hook-mount
  practice; the injected-counter idle probe is its runtime proof (existing
  backlog: React component-test stack).
