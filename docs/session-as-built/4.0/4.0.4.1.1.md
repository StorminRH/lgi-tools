## Delivered outcome

A blank Atlas map is hand-authorable from one root: an editor sets home via a
centered prompt, adds destinations from a node-bound menu, and edits live
connection details (wormhole type, size, mass state, life stage) on an
edge-anchored card. Every public write is field-scoped, equality-skipping, and
`edit`-gated with optimistic fan-out; viewers see no mutation affordances.
Tombstone/restore foundations round-trip identity with a 24-hour undo window
and no destructive connection UI — reserved for 4.0.4.1.2's collapse pathway.

## Divergences from plan

- **Plan statement:** PD-2 home prompt gates on `canEdit && systems complete &&
  zero live systems` via the chain host's empty canvas state.
  **Built instead:** home prompt also requires `liveSystemCount === 0` from the
  filtered subscription pages, not the async merged `state.systems` map.
  **Why:** merged state lags the layout worker, so a populated map briefly
  looked empty and flashed the home prompt.
  **Authority:** Evidence: Diff-mode adversarial holistic review (2026-08-04).
- **Plan statement:** optimistic add inserts the destination system into the
  local paginated systems pages (helper choice unspecified).
  **Built instead:** destination systems use `insertAtBottomIfLoaded`; home on
  an empty map still uses `insertAtTop`.
  **Why:** systems pages are ascending creation order and `resolveRoot` takes
  `facts.systems[0]`; prepending made the destination the transient root under
  production latency.
  **Authority:** Evidence: Diff-mode adversarial holistic review (2026-08-04).
- **Plan statement:** `mapAuthoring` is the sole client-callable chain write
  surface after this session; fixture writes remain internal/admin.
  **Built instead:** public `mapFixtures.upsertSystem` removed; tests and CLI
  use `placeSystemFixture` / authoring mutations.
  **Why:** the legacy public upsert let an editor craft a disconnected system
  outside HC-1.
  **Authority:** Evidence: Diff-mode adversarial ownership review (2026-08-04).
- **Plan statement:** G-1 camera/search feel left to live operator review.
  **Built instead:** `CAMERA_FIT_MAX_ZOOM = 0.75`; MapChrome register-all;
  overlay portal for TerminalSearch-in-Dialog; home `container={null}`;
  add-connection autofocus; unique typeahead codes for SDE clone typeIds
  (C729/F216/J244) with full typeId wire payload preserved.
  **Why:** G-1 live review remediations accepted before in-branch commit.
  **Authority:** Operator: G-1 ACCEPT 2026-08-04 at tip `86026486`.
