## Delivered outcome

A tracked scout's wormhole jump now authors the destination system and
connection for every map viewer with zero interaction, adds the observed
ship's mass to the crossed hole's odometer, links the origin-side signature
when elimination leaves exactly one credible candidate, and emits a
privacy-safe five-column wormhole observation; scanned wormhole signatures
live as unresolved connection rows invisible to every shipped chain consumer,
and pilots can confirm or correct an automatic link from a non-blocking
prompt or the connection card. Map settings became autosaved page-settings
preferences, and the current-system readout became a persistent click-through
overlay.

## Divergences from plan

- **Plan statement:** Doorbell/evidence keyed on the tracked location's `observedAt` (frozen interface had no stable jump epoch).
  **Built instead:** Optional `characterLocation.transitionObservedAt`, advanced only on first insert or a genuine system change; jump evidence, the exactly-once stamp, and the client ring-once memory all key on it. Legacy rows re-anchor until their next genuine system change.
  **Why:** Dock/undock advances `observedAt`, which would re-ring and re-process without a system change.
  **Authority:** Operator: in-session approval of the transition-epoch field (Ordered work 5–6).
- **Plan statement:** Route Zod contract in `src/composition/jump-resolver/api-contract.ts`.
  **Built instead:** Contract homed in `src/data/maps/api-contract.ts`; route and resolver imports repointed, schemas unchanged.
  **Why:** The mapper zone may not import `composition`; data-slice `api-contract.ts` files are the established client-visible pattern.
  **Authority:** Evidence: Fallow boundary rules (mechanical re-home).
- **Plan statement:** Client observer retries "on later feed updates" only (Ordered work 6).
  **Built instead:** Feed-driven rings plus a bounded 15s interval retry and a 15s request timeout; re-derivable candidate races return `retry` instead of settling, and doorbell transitions older than a 10-minute capture window lapse to re-anchor semantics.
  **Why:** The zero-write stationary path produces no feed update after a jump, so a transiently failed ring would strand the transition; an unbounded transition age would author long-dead crossings as current fact.
  **Authority:** Evidence: close-out adversarial-review findings (reliability seat), matching the plan's own recorded lapse semantics.
- **Plan statement:** Post-UX-gate chrome polish as committed (persistent overlay dock retaining pointer events; `atlas.mapLock` preference; floating-window machinery retained without consumers).
  **Built instead:** The overlay dock is `pointer-events-none` (click-through), the preference is `atlas.autoLayout` with the relock consequence disclosed via a page-settings `description` slot, map chrome stacks above the window layer, and the orphaned floating-window machinery (`drag-resize.ts`, pop-out, resize grip, `WindowRect`, floating placement) was deleted per the delete-parallel-implementations rule.
  **Why:** The passive overlay stole canvas input over a screen region with no dismissal affordance; the lock key inverted its user-facing wording; the floating path had zero production callers.
  **Authority:** Evidence: close-out adversarial-review findings (interface and ownership seats) on the operator's post-gate polish commits.
