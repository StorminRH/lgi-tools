## Delivered outcome

Two browsers watching the same map stay live-synchronized. Two gate-first
paginated Convex queries subscribe to a map's systems and connections as
independently draining feeds over disjoint `by_map` ranges; a pure reconciler
owns the merge and emits the five frozen `MapChainIntent` kinds; the canvas
labels nodes from the versioned client directory with the complete space-class
ladder and parks arrivals on a deterministic provisional grid behind the
placement seam 4.0.3.1 replaces. Positions are client-local; drag protection
covers every node a gesture moves. Access is a live value: losing it resolves
the watching client to a calm no-access state with no error path, and
re-granting it restores the map without a reload. No spinner or refresh
control exists anywhere on the surface.

## Divergences from plan

- **Plan statement:** PD-4 — revoked access surfaces as a `ConvexError`
  `{ code: 'FORBIDDEN' }` thrown during render, caught by a dedicated
  `ChainBoundary` whose calm state resets only by remount; SC-4.1's observable
  is a gated call flipping to that thrown error, and recovery on the same map
  is by navigation or reload only.
  **Built instead:** access is answered as a value. A third public query,
  `watchMapAccess`, subscribes to `{ granted }`; the two chain reads resolve
  the same claim through `tryMapAccess` (the value-returning half of the gate,
  sharing one `by_map_user` lookup with the still-throwing `requireMapAccess`)
  and serve an empty, complete page when it is absent. `NoMapAccess` renders
  from `granted: false`; no error boundary exists in the path and a re-granted
  claim recovers the map live.
  **Why:** a paginated query must return a page, so it could only refuse by
  throwing, and the Convex client raises a live-subscription throw inside its
  own socket callback — a routine revocation surfaced as an uncaught error
  (the dev overlay counted it), and the calm state was terminal until reload.
  **Authority:** Operator: directed the replacement during the G-1 review
  (2026-08-01), explicitly authorizing in-session supersession of PD-4.
  **Superseded proof rows:** the plan's SC-4.1/SC-4.2 observables (a FORBIDDEN
  throw; a boundary catching it) no longer describe the read path. The
  delivered proofs are `convex/mapChain.test.ts` "flips access to not granted
  after claim revocation, without throwing", "restores access and rows when
  the claim is granted again", and "never reads a chain row for a caller
  holding no claim"; the plan-named `ChainBoundary.tsx` surface was deleted at
  design review as a pass-through. A later auditor must not read the plan's
  SC-4 rows as proving a throw path; nothing throws on revocation.

- **Plan statement:** the calm state's copy does not pretend prior access
  existed.
  **Built instead:** the heading reads "You've lost access to this map o7"
  (salute in ISK green), shown to never-had-access callers too.
  **Why:** operator-directed copy from the G-1 review; the revocation reading
  is the common case and the wording was chosen knowingly over neutral
  phrasing.
  **Authority:** Operator: wording directives during the G-1 review
  (2026-08-01).

- **Plan statement:** `use-map-chain.ts` owns the two subscriptions via
  `usePaginatedQuery` directly.
  **Built instead:** the raw Convex hooks live in `@/data/convex`
  (`use-drained-pages.ts`, `use-live-value.ts`, `use-convex-authed.ts`); the
  mapper consumes those slice hooks.
  **Why:** a lint rail owns `convex/react` imports to `src/data/convex/**`
  plus two named providers; widening the exemption would have created a second
  Convex consumer surface.
  **Authority:** Evidence: `eslint.config.mjs` vendor-import patterns and the
  `@/data/convex` ownership block.

- **Plan statement:** the demo driver seeds "a Neon map and owner grant".
  **Built instead:** the uncommitted driver seeds the map only; ownership
  flows from `maps.user_id`, so `computeMapAccessClaims` already yields the
  owner claim and a `map_access` grant row would have been redundant.
  **Why:** the projection derives the owner role from map ownership.
  **Authority:** Evidence: `src/composition/map-access-projection.ts`
  (`computeMapAccessClaims`) and the projection result (`inserted: 1`).

## Final surfaces

- `convex/mapChain.ts` — `watchMapAccess`, `watchMapSystems`,
  `watchMapConnections`; gate-first, one indexed `.paginate()` per chain read,
  `numItems` clamped to `MAP_CHAIN_MAX_PAGE_SIZE = 100`, empty complete page on
  denial.
- `convex/lib/mapAccess.ts` — `requireMapAccess` (throwing, mutations) and
  `tryMapAccess` (value, subscriptions) over one shared `resolveMapPrincipal`
  claim lookup.
- `convex/mapFixtures.ts` — adds internal-only `removeSystemFixture` (129-row
  bounded fail-closed scan, refuses while referenced) and
  `removeConnectionFixture`; both idempotent.
- `src/data/convex/use-drained-pages.ts`, `use-live-value.ts`,
  `use-convex-authed.ts` — the slice-owned subscription seams.
- `src/mapper/chain/intents.ts` — the frozen five-kind `MapChainIntent` union
  (members deliberately unexported), `MAP_CHAIN_INTENT_KINDS`, `samePosition`.
- `src/mapper/chain/reconciler.ts` — pure `reconcileChain` (state + snapshots +
  protection set + assigner → state + intents), `applyUserPlacement`,
  `EMPTY_CHAIN_STATE`; protection derived from state as well as the caller's
  drag set.
- `src/mapper/chain/placement.ts` — `PlacementAssigner` seam and the
  deterministic row-major `gridAssigner` (never repositions in production).
- `src/mapper/chain/labels.ts` — directory-driven labels; complete class
  ladder (C1–C6, HS/LS/NS, Thera, C13, Drifter 14–18, Pochven).
- `src/mapper/chain/nodes.ts` — `syncNodes` (preserves library-owned node
  state; holds dragging nodes' local positions) and `buildEdges`.
- `src/mapper/chain/use-map-chain.ts` — the two split subscriptions, the
  access value, the tested `chainSignature` merge guard, label resolution,
  `pinPlacement`.
- `src/mapper/chain/ChainHost.tsx` — identity gate, group-aware drag
  protection (node and selection drags), calm-state rendering from
  `access === false`.
- `src/mapper/chain/NoMapAccess.tsx` — the calm state; no retry control.
- `src/mapper/canvas/ChainSurface.tsx` — the shared React Flow frame;
  `deleteKeyCode={null}`, `disableKeyboardA11y` (read-only session owns no
  mutation affordance).
- `src/mapper/canvas/SystemNode.tsx` — the labelled node with optional class
  chip.
- `src/mapper/canvas/MapCanvas.tsx` — client-side `map` query param, null-client
  gate, host keyed by map id; no error boundary of its own.

## Successor notes

- 4.0.3.2 binds motion to `MapChainIntent`; the reconciler's `intents` output
  is returned but deliberately unconsumed this session. The `system-moved`
  emission path is real and test-driven via the assigner seam; the grid never
  produces one in production.
- 4.0.3.1 replaces `gridAssigner` behind the same `PlacementAssigner` seam; the
  reconciler and intent contract must not change. The assigner is consulted on
  every merge for every unprotected node — do not narrow it to first
  appearance.
- Every page of a paginated query is its own handler execution and re-runs the
  gate, so claim reads scale as `1 + ceil(N/100) + ceil(M/100)` per open; the
  full cost shape lives in `docs/SCRATCHPAD.md`.
- The identity gate in `ChainHost` suppresses a false calm-state flash during
  the socket-connect-to-JWT window (`granted: false` is a legitimate value for
  an identity-less caller); removing it does not restore an error, it
  manufactures a wrong state.
- A revoke/re-grant cycle loses local placements: positions are per-session
  client state (decision D1), and the calm state keeps subscriptions mounted so
  recovery is live. Not a defect.
