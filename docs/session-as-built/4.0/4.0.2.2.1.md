## Delivered outcome

Convex now holds fine-grained map chain tables and a gate-first fixture API:
authorized callers can page one payload collection at a time and upsert systems
idempotently, while signature merge, reversible tombstones, bounded expiry
cleanup, and off-payload last-seen activity are proven through internal fixtures.

## Divergences from plan

- **Plan statement:** Public fixture read `readMap({ mapId, cursors })` with one
  `.paginate()` per systems/connections/signatures/notes collection inside a
  single query (Interfaces and contracts; Ordered work §3; SC-3).
  **Built instead:** Public `readMapCollection({ mapId, collection, cursor })`
  with exactly one gate-first `.paginate()` per call; callers iterate each
  collection until `isDone`.
  **Why:** Convex 1.42.3 / convex-test enforce a single `.paginate()` per
  function execution; the multi-collection `readMap` interface is infeasible.
  **Authority:** Operator: approve alternative 2 (`readMapCollection`) and
  supersede the conflicting `readMap({ mapId, cursors })` interface; Evidence:
  convex-test runtime error linking https://docs.convex.dev/database/pagination.
