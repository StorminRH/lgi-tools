## Delivered outcome

A signed-in admin can create a map from a dialog, land on the set-home prompt, switch maps from the top-center name, edit character and corporation grants through one shared editor, delete into a 30-day trash with restore, and fast-forward purge as creator only. Atlas without `?map=` is a site-framed catalogue; a selected map covers that chrome with the canvas. Roles are viewer/editor/admin. Atlas stays off the public header.
