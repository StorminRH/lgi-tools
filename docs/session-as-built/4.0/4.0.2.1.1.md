## Delivered outcome

Atlas now has an administrator-walled, full-viewport empty map canvas with
floating application chrome, while every existing route retains its URL and
site frame behind a separate route-group layout.

## Divergences from plan

- Contract DC-2 and AC-2 required a debounced resize re-fit; the approved plan
  resolved PD-4 to preserve the camera on resize instead, so the viewport grows
  or shrinks without moving the user's view. Authority: operator direction.
- The adversarial-review runner accepted only plain Markdown labels, so its
  parser and fixture suite were extended to accept the bold labels emitted by
  current reviewers. Authority: discovered evidence.
- The document-reference checker treated completed as-built records as live
  path inventories, which made this route-only relocation invalidate prior
  history. Final as-built records now receive the same historical treatment as
  frozen plans and contracts. Authority: discovered evidence.

## Final surfaces

- `src/app/(map)/` — owns the Atlas route, full-viewport frame, server-side
  administrator wall, and application-layer map chrome composition.
- `src/mapper/` — owns the empty React Flow canvas and the deny-by-default
  mapper boundary surface.
- `src/app/(site)/` and `src/components/composition/SiteFrame.tsx` — own the
  unchanged site-route frame outside the full-screen map shell.
- `scripts/route-presence.mjs` and `scripts/route-classification.json` — resolve
  route groups without changing public route keys and register `/atlas`.
- `.agent-local/run_adversarial_review.py` and `.agent-local/check_doc_refs.py`
  — accept reviewer Markdown emphasis and preserve historical as-built paths.

## Discovered work

- Movable or individually hideable Atlas chrome was recorded in

## Successor notes

- `/atlas` remains server-walled to administrators until the version audit
  removes that gate.
- An authorized user with no active character still receives the canvas and
  non-account chrome; only the account control is omitted.
- `src/mapper/` may consume approved lower surfaces, but features and
  authentication-owned composition must never import upward into it.
