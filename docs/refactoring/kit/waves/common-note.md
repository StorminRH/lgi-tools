Convex code runs in the Convex runtime: it cannot import Node-only modules, and anything shared between Next and Convex must be runtime-portable (Web Crypto, no node:crypto). When a Convex module's exports change, regenerate convex/_generated with `pnpm exec convex codegen --typecheck disable` against the local backend (start it only if needed, and stop anything you start). Do not export a constant or helper that only tests read: Fallow's production dead-code pass in pnpm verify counts only production references. Visual or browser checks the write-ups ask for cannot be done here (no dev server): list them in your deviations as "not checked by eye" so the PR can name them. Pre-existing bugs or flaky tests you hit are fixed in this wave, per the repo owner, and noted in your summary. When an item edits eslint.config.mjs, also run `pnpm exec vitest run scripts`: the rail tests there (syntax-exemption-rail, ui-adoption-rail) pin each exemption owner, and the changed-set run in pnpm check does not pick them up.
