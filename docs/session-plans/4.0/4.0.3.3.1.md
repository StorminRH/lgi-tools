## Why now

The map shell, live chain, layout, and motion are in place, but the Atlas still has no standing place to show “where I am” or a glance at another system. Every later surface that needs detail over the canvas (connection intel, signatures, D15 widgets) depends on one host-layer window primitive; introducing a second window system later would be architecturally irreversible. This session lands that primitive with stub content so later slices fill the slot rather than inventing chrome.

## Scope (the destination)

When this session ends, the admin Atlas map presents two user-visible windows built on one primitive:

1. **Current-system dock** — a persistent readout for the stub current system (first system in the sample/fixture chain). Default presentation is fixed-size edge-docked. The operator may pop it out into a free-floating window, drag and resize it freely, and reload restores via grid-slot encoding on the same device. Canvas clicks and Escape do not close it; only its close control does. Content updates when stub current changes; real location later replaces the stub.
2. **Glance card** — selecting a system other than current opens a node-anchored summary (placeholder content) that tracks pan/zoom via a cheap host-layer tracker. It dismisses on intentional canvas click (not pan-drag), deselection, Escape, or its close control. The dock stays up.

Typing and scrolling inside either surface never pan or zoom the map. Clicking a window brings it forward. Nothing is modal. The dock's content slot hosts `SiteCardWidget` through the shipped props contract (fixture `siteId` for hosting proof only — not real system intel). All three modes (docked, floating, node-anchored) resolve to the same shell in the mapper host layer above the canvas.

Contract §3 done conditions are met with the operator override on dock lifetime recorded under hard constraints and PD answers; §4 in-scope items map below; §5 exclusions stay untouched; §6 constraints are in the hard-constraints block.

## Resolved implementation decisions

- **Contract PD-1 — Pointer-event architecture: host-layer opaque siblings with DOM hit-testing.** Windows mount as positioned siblings above the canvas under `ReactFlowProvider`. Events that hit a window never reach the canvas; uncovered regions keep today's pan/zoom. React Flow `nopan`/`nodrag`/`nowheel` are not the isolation mechanism (they apply only inside the canvas). **Rejected:** globally disabling pane interactions while any window is open (violates HC-5) and implementing windows as in-canvas `Panel` nodes to reuse those classes (violates HC-3).
- **Contract PD-2 — Primitive separability: chrome shell with a content slot.** The shell is presentational chrome + content slot only. A single **window-layer stack owner** (not the shell, not either surface controller alone) assigns `stackZ` and handles activation/bring-to-front for all mapper windows. Persistence and selection stay in their controllers. Consumers pass React children (D15 widget or placeholder). No sites/signature types leak into the shell props. **Rejected:** baking `SiteCardWidget` into the shell; per-surface chrome forks; letting each controller maintain an independent z-index authority.
- **Contract PD-3 — Per-device persistence: free drag/resize at runtime; grid-slot quantization only at save; mode is part of the record.** While floating, the user drags and resizes continuously (no snap-to-grid interaction — OOS-3). On drag/resize end, encode `{ v, mode:'floating', slotId, sizeBand }` into mapper-owned localStorage (not `PREFERENCES` / server KV). **Re-docking writes `mode:'docked'`** (clearing floating geometry) so reload cannot resurrect a float. On restore: floating+valid → float rect (clamp if needed); docked/invalid/missing/corrupt/unwritable → default edge-docked. **Rejected:** snap during gesture, raw-pixel-only persistence, server-synced geometry, and leaving a stale floating record after re-dock.
- **Contract PD-4 — Node-anchored tracking: provider-sibling leaf tracker with imperative CSS updates.** Glance sits in the host layer; a tiny tracker updates `transform`/`top`/`left` via refs from `flowToScreenPosition` + internal node position on **viewport changes and selected-node position changes** (drag/motion). Prefer `useOnViewportChange` plus a narrow node-position subscription; any `useStoreApi().subscribe` path must dispose on glance close/retarget/unmount. Do not put `useViewport` high in the tree. **Rejected:** `ViewportPortal` / in-canvas anchoring (wrong layer for HC-3), viewport-only tracking that drifts when the node moves, and React state updates every move frame on a large tree.
- **Plan PD — Dock lifetime (operator 2026-08-02): persistent current-system readout with explicit hide/reopen.** Dock opens with stub current, stays across canvas clicks and Escape, and closes only via its close control. Close sets an **in-memory** `dockUserHidden` flag (not persisted — reload always shows the dock). Reopen: `onNodeClick` on the current system clears `dockUserHidden` and shows the dock again. Escape never closes the dock. **Rejected:** contract's close-on-canvas-click for the dock; persisting "hidden" across reload (fights persistent readout); deferring reopen to an undefined G-1 invention.
- **Plan PD — Glance lifetime and multi-select.** Glance target is set only by `onNodeClick` on a non-current system (last clicked other system wins). Multi-select / rectangle select does not invent a second glance rule. Every dismiss path — pane click without drag, Escape, glance close, target leaving the chain, **or the glance target becoming deselected / becoming current** — runs one shared transition: clear `glanceTarget`, dispose tracker, set `glanceSuppressed` until a fresh other-node click. Pan-drag does not dismiss. Feel thresholds for click-vs-drag tuned at G-1 against React Flow `paneClickDistance`. **Rejected:** binding glance to the full multi-select set and Escape closing the dock.
- **Plan PD — Stub current identity: first system in the sample/fixture chain.** `ChainHost` (or the chain host seam) **derives** `currentSystemId` as the first system id in the reconciled chain each merge and passes it into the window layer. If that system departs, derivation picks the new first system (dock content follows); if the chain is empty, dock shows a calm empty state and reopen-on-click is inert until a system exists. Sticky rule until 4.0.4.2 replaces derivation with location. **Rejected:** treating every selection as current; duplicating derivation inside `DockController`; inventing a “set current” control this session.

## Implementation blueprint

### Owned surfaces

- `src/mapper/window/` (new module family) — presentational shell, `WindowStack`, grid-slot persistence codec, isolation helpers, dock + glance controllers, tracker.
- `src/mapper/canvas/MapCanvas.tsx` / new thin `MapHost` (as needed) — relative host wrapping `ReactFlowProvider`, canvas, and window layer; public mapper entry remains `MapCanvas`.
- `src/mapper/canvas/ChainSurface.tsx` — gains pane-click / selection-change seams required for glance dismiss/deselection; still the only home for in-canvas `Panel` children (`MapControls`, camera follow).
- `src/mapper/chain/ChainHost.tsx` — derives stub `currentSystemId` from the reconciled chain, forwards selection/click seams to the window layer, owns no chrome.
- `src/features/wormhole-sites/widget.tsx` — unchanged; consumed as dock slot content for D15 proof.
- `src/mapper/chain/surface.test.ts` (or successor census) — census rows for new production modules.
- Focused tests under `src/mapper/window/**` — isolation, grid codec, stack/dismiss model.

### Interfaces and contracts

- `WindowShell` (presentational only) — discriminated props by mode (`docked` | `floating` | `node-anchored`): `title`, `stackZ`, `onClose`, `onActivate`, `children`, plus mode-specific geometry props. No persistence, selection, tracking, or stack-authority logic inside the shell. Docked: fixed size + edge anchor, no resize handles. Floating: continuous drag/resize (no snap); reports rect on gesture end. Node-anchored: positioned by tracker; not user-resizable.
- `WindowStack` (single owner) — pure/stack host that records activation order and supplies `stackZ` + `onActivate` to every mounted shell; the only bring-to-front authority in the window layer.
- `grid-slot codec` — pure versioned encode/decode for `{ v, mode, slotId?, sizeBand? }`; safe-parse failures and clamp-on-restore; unit-tested without DOM.
- `DockController` — sole owner of `dockUserHidden`, docked/floating mode, persistence read/write (including `mode:'docked'` on re-dock), reopen-on-current-click. Receives derived `currentSystemId` from `ChainHost`; does not re-derive it.
- `GlanceController` — sole owner of `glanceTarget` / `glanceSuppressed`, shared dismiss/rearm transition (including deselection), tracker subscribe/dispose/retarget; sets glance from `onNodeClick` other-system only.
- `SiteCardWidget` — `{ siteId: number; className?: string }` unchanged; host supplies a fixture `siteId` suitable for admin preview.
- No new Convex functions; no preferences registry keys for geometry.

### Control and data flow

1. `MapCanvas` / host mounts `ReactFlowProvider` → canvas (`ChainHost`/`ChainSurface`) + window layer siblings.
2. On live chain load, stub current = first system id in the reconciled chain → `dockUserHidden=false` → dock presents (docked default or restored float rect from grid slot).
3. `onNodeClick` on a non-current system → set glance target (clear suppression); dock unchanged. Click current while hidden → clear `dockUserHidden`.
4. Viewport or glance-node position moves → tracker updates CSS transform imperatively; disposer runs on close/retarget/unmount.
5. Pointer down on a window → stack bring-to-front (Escape still affects glance only, never dock).
6. Floating drag/resize end → encode versioned `{mode:'floating', ...}` → localStorage (runtime geometry stayed free during the gesture). Re-dock → write `{mode:'docked'}`.
7. Reload → safe-decode: floating+valid → float (clamp if needed); docked/invalid → default dock; `dockUserHidden` always false after reload.
8. Failures: missing/corrupt/throwing localStorage → default dock (no throw into Atlas); glance target missing or deselected → shared dismiss+suppress; empty chain → calm empty dock; widget fixture error → widget-owned calm error inside slot.

### Edge and failure behavior

- Private / cleared / corrupt / unwritable storage → default edge-docked dock; never throw into the Atlas host.
- Glance target node leaves the chain → dismiss + suppress until a new other-node click.
- Canvas pan-drag → glance persists; pane click without drag → dismiss + suppress.
- Manual dock close → `dockUserHidden=true` (memory only); reopen by clicking the current system node; reload clears hide.
- Re-dock from floating → persist `mode:'docked'` so reload stays docked.
- Current system departs → derivation selects new first system (or empty calm state); glance target that becomes current dismisses.
- Split trigger: if absolute isolation requires changing shipped canvas event handling beyond host-layer coverage → pause for operator direction (contract split trigger).

2. **Window primitive.** Add `src/mapper/window` shell with docked/floating/node-anchored modes, chrome controls, and content slot. Prove with component tests that mode switches do not remount unrelated consumers unnecessarily and that anchored mode exposes no resize affordance.
3. **Event isolation.** Apply host-layer hit-testing and prove with SC-4-oriented tests that wheel/keyboard interaction inside the shell does not change viewport zoom/x/y. Stop for operator direction if the split trigger fires.
4. **Persistent dock.** Bind stub current (first sample system); default edge dock; pop-out float with drag/resize; close control only (no canvas/Esc close). Prove open-on-load and non-dismiss from pane click / Escape.
5. **Grid-slot memory.** Implement versioned pure codec + exception-safe localStorage adapter including `mode`; prove round-trip, corrupt/throw fallback, clamp-on-restore, free mid-gesture resize, re-dock persistence, and reload-after-redock.
