## Why now

4.0.4.2 made jumps author the map automatically; scanning is the half of intel that remains manual paperwork. This session turns the paste a scanner already produces into list, stubs, and honest lifecycle — the substrate 4.0.4.3.2's inference and 4.0.4.3.3's ranking/emissions require (both consume the parsed rows, stub presentation, and typed-code flow built here).

## Scope (the destination)

A pilot on the Atlas page pastes scanner output (no field focus needed). The paste applies to their tracked current system: rows upsert with never-regress merge, unchanged rows write nothing, wormhole-group rows live as unresolved `mapConnections` rows (shipped merged model) and render as ghosted stub nodes; everything else stays in the bottom-left signature window (Signatures/Anomalies tabs; ID · name · group columns; signal as a row-background progress fill; client-ticked age). Rows previously known but missing from the paste highlight dim red behind a Remove/dismiss confirmation; a wormhole past its ceiling and missing is removed silently. Removals tombstone with a 24-hour undo; wormhole removals route through the one collapse pathway, as does the cron's grace-buffered ceiling sweep. A right-click row editor hosts the shipped connection field groups (statics-first type picker, life stage, mass, leads-to); typing a code fills class/lifetime from the codex. Jump resolution converts a stub into the real system on the same row. Contract §§3–6 are satisfied without widening: no inference, no ranking-from-profile, no emissions, no sites hosting, no bookmark tooling.

## Resolved implementation decisions

- **Contract PD-1 — Paste format: closed six-column English format, witnessed live.** Tab-separated `ID · kind (Cosmic Signature|Cosmic Anomaly) · group · name · signal% · distance`; closed group vocabulary (Wormhole, Combat Site, Ore Site, Gas Site, Data Site, Relic Site); empty group/name = unresolved; signal may regress in-client while knowledge persists (witnessed `CNN-648`); distance ignored and unit-variant (km/AU); order-independent; unrecognized rows rejected loudly, never guessed. Five operator samples (full, filtered-anomalies, progressed, partial-selection, near-object km) are checked in as parser fixtures. English client only by operator ruling. **Rejected:** localized-vocabulary support — translation tables with no current user need.
- **Contract PD-2 — Removal: evidence-graded confirmation, 24h undo everywhere.** Missing-from-re-paste alone (per-kind scoped: a kind absent from the paste conveys nothing — witnessed by the filtered-anomalies sample) → dim-red highlight + Remove/dismiss affordance, no auto-delete; missing AND ceiling-expired → silent removal; every removal tombstones with `MAP_CHAIN_UNDO_WINDOW_MS` (24h) undo, sig purge sweep newly registered in the cron. This settles the contract's "removed immediately" under PD-2's presentation authority, by operator direction. **Rejected:** immediate auto-remove with short undo — filtered and partial pastes make "missing" too weak an evidence signal; accidental mass deletion would be routine.
- **Contract PD-3 — Stub matching: the stub is the unresolved connection row; resolution is the shipped same-row patch.** A stub node renders an unresolved `mapConnections` row (synthetic node id `stub:<connectionId>`); jump resolution fills `toSystemId` on that same durable row (`resolveCandidateTopology`). No duplicate by construction because stubs derive only from unresolved rows: filling the destination removes the stub's source in the same update that lets the authored system render through the normal reconcile — there is no id collision to dedupe, and the shipped halo id-dedupe/`stripDerivedControls` ladder is untouched. Ambiguity keeps the shipped candidate prompt, now labeled with signature IDs. **Rejected:** separate stub entities matched heuristically at jump time — creates a reconciliation owner the shipped model already makes unnecessary.
- **Contract PD-4 — Window composition: sibling surface, one geometry variant, no primitive extension.** The signature window follows the `connection-details` precedent (own overlay container, `MapWindow` chrome, imported dismiss policies). The only primitive edit is a new `docked-bottom-left` entry in `placementClassName` (its one geometry owner). The window never retargets on node click; other systems' signatures render in the clicked node's System Info card. **Rejected:** extending `MapWindowId`/`deriveSurfaces` — the layer's stack vocabulary is not the extension seam; `connection-details` proves composition works without it.
- **Paste capture — page-level listener, tracked-location target (operator ruling).** A document paste handler on the Atlas page, suppressed when focus is editable or a dialog is open; the target system is the paster's tracked current location, server-verified; untracked or off-map → informative toast, zero writes. Paste-into-selected-system is explicitly out (possible future feature).
- **Ceiling expiry trigger — cron sweep with grace (operator ruling).** The 15-minute map cron gains a sweep over connections with `deathLatestAt + CEILING_COLLAPSE_GRACE_MS` (4h, named constant) in the past, each routed through the internal collapse core with pilot presence computed from tracking data. This is the recorded narrow exception to "no scheduler flips a state."
- **Type picker ordering — statics-first bounded seam.** Statics for the origin system (served by a new small cached read-only route over the shipped statics dataset) sort first; all other codes follow under the existing fuzzy `wormholeTypeSearch`. Owned by one small module .3's merged profile replaces. **Rejected:** unranked picker — foregoes shipped statics data the operator explicitly wants surfaced.
- **Row editing — right-click context menu hosting the shipped field-group primitive.** Base UI menu on rows; wormhole rows expose type/life-stage/mass/leads-to (writing through existing mutations); unresolved rows expose identify-as (group set → Wormhole triggers the sig→connection migration). Plain click on an unidentified row opens the same menu as the secondary affordance. Desktop-only by ruling.
- **Chrome relayout (operator direction).** Audit log + feedback move to bottom-right compact chips with a subtle pulse on undoable events; dev dials move with them; the current-system dock's duplicated name line is removed; Security Status (from existing `security`/`whClassId` facts) joins the dock and the System Info card, which also gains the selected system's signature summary.

### Interfaces and contracts

- `parseScannerPaste(text: string): { rows: ScannedRow[]; rejects: RejectedLine[] }` — total, throw-free; `ScannedRow = { signatureId, kind: 'signature'|'anomaly', group: SigGroup|null, name: string|null, signalPct: number|null }`; a paste with zero parseable rows is a reject result, not a write.
- `applyScan` (Convex mutation) — args `{ mapId, systemId, rows }`; requires map edit access AND `systemId` equal to one of the caller's tracked characters' current on-map systems; one transaction; returns `{ inserted, updated, unchanged, migrated, removedConfident, missing }` where `missing` (per-kind scoped) feeds the client confirmation flow and is never persisted.
- `removeSignatures` (Convex mutation) — args `{ mapId, systemId, signatureIds }` from the confirmed Remove action; sig rows tombstone with 24h undo; wormhole rows route through the collapse core.
- Internal collapse core (Convex, `mapAuthoring.ts`) — `runCollapse(ctx, { mapId, connectionId, actor, pilotsPresent })` for resolved cuts (decideCollapse + shared-stamp writes + ledger event); unresolved rows tombstone via the shared stamp helpers (no branch decision exists for a stub). `severConnection` wraps it unchanged for callers.
- `watchMapSignatures` (Convex query) — gated, paged per-map signature read (tombstones filtered), outside `mapChain.ts`'s read set.
- `GET /api/universe/statics/[systemId]` — cached, read-only `{ statics: string[] }` from the shipped wh-statics queries; empty array on unknown system.
- New/changed UI exports stay internal to `src/mapper/signatures/`. Existing `setConnectionWormholeType`/`setConnectionLifeStage`/hint mutations are consumed unchanged server-side (`to`-side controls now have their planned callers); the only changes to existing shared interfaces are the `wormholeTypeWindowProposal` base rebase and the additive `firstSeenAt`/`fromSignalPct` connection-projection widening, both named under Owned surfaces.

### Control and data flow

Paste → page listener → `parseScannerPaste` → resolve tracked system client-side → `applyScan` (one transaction: verify gate + tracked location; upsert `mapSignatures` non-wormhole rows; upsert/migrate wormhole rows into unresolved `mapConnections` stamping `firstSeenAt`; debounced `mapSignatureActivity` touch; confident removals through the collapse core) → subscriptions fan out (`watchMapSignatures` + existing connection/unresolved-hole queries) → window rows + ghosted stubs render. Removal confirmation → `removeSignatures` → tombstones/collapse → undo via toast + ledger (24h). Cron (15 min) → ceiling sweep past grace → collapse core → stubs/nodes depart through the shipped motion vocabulary. Jump → shipped resolver → same-row `toSystemId` fill → stub id retires, authored node takes the position. Failure boundaries: untracked paste → toast, zero writes; codex/statics route unavailable → picker degrades to fuzzy-search-only (never fakes a static); Convex mutation rejection → optimistic patches roll back per shipped `swallowMutationRejection` pattern.

### Edge and failure behavior

- Filtered paste (a kind absent) → no removal signal for that kind; witnessed sample is a fixture.
- Partial-selection paste → missing rows enter the confirmation flow only; dismiss keeps them.
- Signal regression on re-paste (0.0% with knowledge) → knowledge and best-seen `signalPct` retained; no downgrade write.
- Re-pasted sig for a tombstoned row (same ID inside undo window) → inert to paste (shipped rule), preserving HC-3; a genuinely new hole arrives under a new sig ID.
- Sig→connection migration race with a concurrent jump insert on the same signature → single transaction resolves by upsert-then-migrate order inside `applyScan`; the migration reuses `findUnresolvedHole` convergence semantics.
- Ceiling sweep meets an already-tombstoned or already-resolved-then-severed row → skip; sweep is idempotent and bounded (`by_death_latest` index, batch cap).
- Stub as the cut edge of a manual sever → refused today (`UNRESOLVED_CONNECTION`) and unchanged; stub removal is only via the signature lifecycle or as collateral (`stampRemovedRows`), never via `severConnection`.
- Pilot present in a to-be-orphaned branch during sweep → `decideCollapse` retains the branch (presence computed from tracking rows); the dead connection alone is removed.
- Paste while a row's editor menu is open → capture suppressed (editable-focus guard).
