## 1. Objective

Integrate the shipped inference/provenance model with honest ranking, privacy-safe
typed observations and the complete operator-facing signature experience.

## 2. Current context and dependencies

- **DEP-1:** Session 4.0.4.3.1 shipped signature lifecycle and stubs.
- **DEP-2:** Session 4.0.4.3.2 shipped the pure inference, provenance and degraded-mode contracts.
- **DEP-3:** Decision D16 fixes origin-side attribution, anti-circularity and acceptance-versus-override weighting.
- **DEP-4:** The sites widget and window contracts are already shipped.

## 3. Done conditions

- **DC-1:** The pick list is ordered only from the merged per-system profile.
- **DC-2:** Provenance is visibly distinct and contradictions yield without overriding a person.
- **DC-3:** Accepted and overridden typed identifications emit differently weighted observations.
- **DC-4:** Inferred values never emit, and far-side untyped values are never attributable.
- **DC-5:** A site-type signature opens the sites widget through the shipped contracts.

## 4. In scope

- **IS-1:** Ranking and provenance presentation.
- **IS-2:** Typed observation emission and its privacy/attribution boundary.
- **IS-3:** Sites-widget hosting and final signature UX.

## 5. Out of scope

- **OOS-1:** Observation scoring, confidence overrides and public serving.
- **OOS-2:** Changes to the parser, lifecycle, solver or collapse pathway.

## 6. Hard constraints

- **HC-1:** Ranking derives from one merged profile; no parallel ranking owner exists.
- **HC-2:** Inferred values never enter the observation stream.
- **HC-3:** Events carry no map or pilot identity and attribute only to the origin side.

## 7. Decisions the session plan must resolve

- **PD-1:** Acceptance-versus-override weights and their capture point.
- **PD-2:** The operator-facing provenance and contradiction presentation.
- **PD-3:** How the merged profile graduates from bootstrap data without self-confirmation.

- **AC-2:** Each provenance tier is distinct and a conflicting inference yields — proving DC-2.
- **AC-3:** Acceptance and override emit different weights — proving DC-3.
- **AC-4:** Inferred and far-side untyped cases emit no attributable observation — proving DC-4 and HC-2.
- **AC-5:** A site row opens the shipped widget in the shipped window — proving DC-5.
