## v4.0 — Atlas of Worlds

v4.0 lays the groundwork for a collaborative wormhole mapper while keeping its delivery records and measurement baseline trustworthy from the first shipped slice.

### v4.0.3.1 — 2026-08-02

#### Added
- The Atlas map now lays out the chain automatically as a compass tree: home sits at the center, every jump lands one ring further out, and branches claim compass directions in the order they are found. Every pilot watching a map sees the identical picture, even across different browsers.
- Systems draw as circled class markers with the system name beneath, and connections draw as straight lines meeting each circle at its edge. Shortcut connections that close a loop draw dashed so the chain structure stays readable, and duplicate links never draw as structure twice.
- A map lock keeps the layout in charge: unlock to drag nodes around freely on your own screen, then re-lock to snap everything back to its computed place. Hand arrangements are never visible to anyone else.
- A tuning panel exposes the layout dials — ring spacing, separation, sibling fan, wedge posture, and direction order — and changing one re-draws the chain live on that screen only. The shipped defaults are the values tuned and signed off against live replayed chains.
- A camera-follow toggle brings new arrivals into frame when enabled. The view frames the chain once when a map opens and otherwise never moves on its own.
- A developer replay tool feeds realistic generated chains into a local map at watching pace, with a loop mode that repeatedly grows and tears down the chain to exercise arrivals and departures.

#### Changed
- Chain layout is computed by a deterministic compass-sector engine selected over ELK radial after a measured bake-off, and the computation runs in a background worker loaded only on the map route, keeping the page responsive and other pages free of layout code.
- The layout engine computes its own trigonometry instead of using the browser's, making node positions identical on every JavaScript engine by construction.
- The provisional placement grid is gone; the layout engine is now the only thing that has ever placed a node on the live map.
- The map library's corner attribution badge is hidden per its project's stated permission, with a styled credit planned for a future footer pass.

- Generalized the development lifecycle so supported coding agents share global discovery skills, context-isolated native subagents, visible repository tools, and portable review roles.

- Standardized repository mapping on the required global Codegraph CLI without requiring or installing a Codegraph MCP.
- Input cost uses the same green figure color as sell and margin.
- Tab icon uses the header-style [LGI] wordmark instead of the boxed mark.
- Agent guidance treats Codegraph MCP explore as available alongside the CLI, with status, sync, query, callers, impact, and other non-explore commands remaining CLI-only.
- Promoted explicit native subagent production configurations and clarified when agents should delegate bounded research, verification, and review work.
- Reliability reviewers now require a demonstrated trigger, reachable unsafe transition, and material impact before reporting a finding.
- Absorbed sixteen Vercel/Next.js and three Upstash platform notices from three backlog update-watch digests into the acknowledged baseline.
- Recorded the missing xyflow React major-12 acknowledgement in the update-watch baseline.
- Focused always-on agent guidance on shared policy, moved source and Convex rules to scoped owners, and reserved CodeGraph for relationship evidence.
- Made current documentation research conditional on material external behavior rather than a fixed every-task preflight.
- Tightened workflow wording for outcomes and authority, and encouraged optional research and verification subagent roles without restoring fixed preflight.

#### Fixed
- Restored automatic deployment to production, which stopped after an internal page reorganisation changed the address of the wormhole site preview image.
- Live price confirmation now flashes once when a value settles and stops cleanly, instead of keeping a multi-peak blink after the update lands.
- Industry planner no longer crashes when live prices settle after a refresh.
