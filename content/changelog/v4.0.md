## v4.0 — Atlas of Worlds

v4.0 lays the groundwork for a collaborative wormhole mapper while keeping its delivery records and measurement baseline trustworthy from the first shipped slice.

### v4.0.5.1 — 2026-09-02

The mapper sits in the public site header and the home tools list, and a signed-out visitor lands on the map catalogue instead of an administrator wall, so a shared map link still reaches the login button. The map lifecycle now blocks restore and republish once a purge has started, and a stale access record can no longer bring a revoked claim back. Staging lives at its durable host and talks to Convex staging, in-app feedback files a Linear issue with a required title, and the ESI drain and sync watchdog no longer run every fifteen minutes on Vercel.

Atlas connections now store as one hallway with two mouths, each a class hint or a known system but never both, so a named wormhole shows its type in the scanner even when the first stored mouth is a K162. Harvestable site prices use the Jita best sell, and stored Jita buy figures drop hub bids under 35 percent of the hub ask. The Under the Hood pages are gone; the changelog stays in the footer.
