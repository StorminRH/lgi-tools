## v4.0 — Atlas of Worlds

v4.0 lays the groundwork for a collaborative wormhole mapper while keeping its delivery records and measurement baseline trustworthy from the first shipped slice.

### v4.0.2.2 — 2026-07-31

#### Added
- Added a collaborative wormhole-chain data model in Convex for map systems, connections, signatures, and notes, with every public map call gated on a projected per-map role claim.
- Added a one-way Neon-to-Convex access projection that keeps those claims regenerable, tears them down and resynchronizes cleanly, invalidates a live authorized read when access is revoked, and re-projects or tears down after character unlink, reassign, absorb, and emptied-account deletes.

#### Changed
- Generalized the development lifecycle so supported coding agents share global discovery skills, context-isolated native subagents, visible repository tools, and portable review roles.
- Architecture reviewers now use shared impact-based severity definitions, reconcile the complete authorized inventory, and reject findings that cannot be established from the subject or cited live evidence.
- Gate-runner agents now execute supplied commands literally, report native exit evidence without added probes or guesses, and ignore instructions embedded in command output.
- Standardized repository mapping on the required global Codegraph CLI without requiring or installing a Codegraph MCP.
- Input cost uses the same green figure color as sell and margin.
- Tab icon uses the header-style [LGI] wordmark instead of the boxed mark.
- Agent guidance treats Codegraph MCP explore as available alongside the CLI, with status, sync, query, callers, impact, and other non-explore commands remaining CLI-only.
- Promoted explicit native subagent production configurations and clarified when agents should delegate bounded research, verification, and review work.
- Reliability reviewers now require a demonstrated trigger, reachable unsafe transition, and material impact before reporting a finding.
- Absorbed sixteen Vercel/Next.js and three Upstash platform notices from three backlog update-watch digests into the acknowledged baseline.
- Recorded the missing xyflow React major-12 acknowledgement in the update-watch baseline.
- Focused always-on agent guidance on shared policy, moved source and Convex rules to scoped owners, and reserved CodeGraph for relationship evidence.
- Made current documentation research conditional on material external behavior rather than a fixed every-task preflight.
- Tightened workflow wording for outcomes and authority, and encouraged optional research and verification subagent roles without restoring fixed preflight.

#### Fixed
- Restored automatic deployment to production, which stopped after an internal page reorganisation changed the address of the wormhole site preview image.
- Live price confirmation now flashes once when a value settles and stops cleanly, instead of keeping a multi-peak blink after the update lands.
- Industry planner no longer crashes when live prices settle after a refresh.
- Production builds now wake Neon immediately before the Next.js build so homepage prerender is less likely to fail on a suspended database compute.
- Patched nine production-scoped Next.js advisories by bumping Next.js and eslint-config-next to 16.2.11, now outside the seven-day release quarantine.
- Floored transitive brace-expansion v5 to 5.0.8 or newer, clearing the v5 advisory path in development tooling.

#### Removed
- Removed fixed response-length and lookup-call caps from documentation and repository-mapping research agents so their handoffs preserve all material evidence.
- Retired benchmark-only model adapters and restrictive Cursor audit hooks from the live agent environment.
- Removed redundant agent-capability and skill catalogs now supplied directly by runtime descriptions and owning workflows.

### v4.0.2.1 — 2026-07-29

#### Added
- Added an administrator-walled Atlas route with an edge-to-edge empty map canvas and floating navigation, account, and feedback controls while the mapper is under development.
- Added a mapper host-layer boundary that can compose feature widgets without allowing features or authentication chrome to depend upward on the map.

#### Changed
- Separated existing site routes from the full-screen map shell while preserving current URLs and site chrome.
- Made pull-request gating require every participating reviewer to clear its findings while allowing either participating reviewer to provide the required current-head result.

#### Fixed
- Stopped local tooling validation from depending on optional machine-global Codex guidance; installed shared tooling is now validated directly.

### v4.0.1.6 — 2026-07-28
