## v4.0 — Atlas of Worlds

v4.0 lays the groundwork for a collaborative wormhole mapper while keeping its delivery records and measurement baseline trustworthy from the first shipped slice.

### v4.0.2.1 — 2026-07-29

#### Added
- Added an administrator-walled Atlas route with an edge-to-edge empty map canvas and floating navigation, account, and feedback controls while the mapper is under development.
- Added a mapper host-layer boundary that can compose feature widgets without allowing features or authentication chrome to depend upward on the map.

#### Changed
- Separated existing site routes from the full-screen map shell while preserving current URLs and site chrome.
- Made pull-request gating require every participating reviewer to clear its findings while allowing either participating reviewer to provide the required current-head result.

#### Fixed
- Stopped local tooling validation from depending on optional machine-global Codex guidance; installed shared tooling is now validated directly.

### v4.0.1.6 — 2026-07-28

#### Added
- Added a weekly, versioned copy of per-system wormhole statics that keeps serving from the last operator-approved snapshot when the community feed is unavailable.
- Added an admin review screen that shows feed differences and independent lineage disagreements before a snapshot can be promoted.

### v4.0.1.3 — 2026-07-28

#### Added
- Added versioned client reference data for solar-system details, stargate connections, and wormhole type attributes that the upcoming mapper can load once per session.
- Added the first embeddable feature widget, letting a host render the existing wormhole site card from a site identifier inside its own window.

#### Changed
- Browser tabs and bookmarks now show the LGI mark instead of the placeholder icon the site shipped with.
- Changelog entries no longer end with a note about which earlier version a change first shipped in.

### v4.0.1.1 — 2026-07-27

#### Added
- Added durable map identity and delegated character or corporation access in Neon, with one authorization gate that resolves owner, editor, viewer, and denied capabilities.
- Character-transfer and account-deletion teardown now removes direct map grants and user-owned maps before identity can move to another person.

#### Changed
- Expanded adversarial reviews with up to three focused Composer passes and compact, deduplicated findings.

### v4.0.0.1 — 2026-07-27

#### Added
- The code-health baseline now captures each master version's starting reference, measures its expanded lifecycle surfaces, and preserves session as-built records in version archives.

#### Changed
- Absorbed three days of no-impact Vercel/Next.js and Neon platform notices into the update-watch baseline so the daily digest stops re-reporting them.
- Compacted the 3.10 scratchpad for the 4.0 boundary and redirected historical margin-audit and document evidence to their archive homes.

#### Fixed
- Cleared the eligible Better Auth, PostCSS, fast-uri, Babel, esbuild, and Vite advisories, and refreshed the mature React, Convex, Tailwind, Vitest, lint, and supporting package lines.
- Pinned the repository and CI to a pnpm release that actually enforces the seven-day install quarantine.
- Bounded documentation path checks to complete filenames and Markdown link targets so valid prose cannot hide or manufacture a dead-path claim.
