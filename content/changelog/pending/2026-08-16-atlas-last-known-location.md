#### Fixed
- Atlas only shows a tracked pilot on the map when that owner is present and the character is online.
- Closing the Atlas tab hides the pin and stops location polling instead of waiting for the five-minute heartbeat silence.
- Deleting a mapped wormhole no longer blocks re-pasting that signature; Atlas starts a new unresolved hole instead of keeping the old branch locked.
- Marking a signature as the way home keeps that hole on one connection. Re-pasting the same block no longer draws a second ghost for the return path.
- Jumping a remapped hole no longer underlines the new connection with the deleted hole's dying line.
- The scanner list uses the same painted scrollbar as the rest of the site.
