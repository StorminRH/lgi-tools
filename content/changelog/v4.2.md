## v4.2 — Codex

4.2 opens Codex, a field guide to wormhole space inside LGI.tools. Pilots write the advice, and the game data stays live.

### v4.2.0 — 2026-10-04

Codex has its first pages. Each guide opens at its own address with a contents list beside the text, and the Codex home lists every guide. Guides can hold headings, lists, quotes, tip boxes, tables, and links.

#### Added
- A Codex home that lists every guide.
- Guide pages with a breadcrumb, sections, and an "On this page" list.
- Every guide keeps its full edit history, and its text is shared under CC BY-SA 4.0.
- The site admin can start a new guide, edit one section or the whole page in place, and restore an earlier version from the page history. Readers never download the editor.
- The site admin can place live game data in a guide: a wormhole type, a site, a wormhole class, or any item, shown as an info box, a table, a value inside a sentence, or the site card. The numbers come from the game data and update when it does.
- Every wormhole type, site, and wormhole class has its own Codex page with its live game data and sections ready to write, and the Codex home shows each kind with its count, a title search, and the latest edits.
- Any signed-in pilot can suggest an edit to a Codex page. The site admin reviews suggestions in the admin console, and accepted ones credit the pilot at the bottom of the page.
- A suggestion still goes in after the page changed: edits to different parts merge on their own, and the site admin settles any paragraph both sides changed by seeing the original, the page now, and the suggestion side by side.
- Guides can hold screenshots: paste or drop an image into the editor, add alt text, and readers get a small sharp copy sized for their screen; a suggested image waits for review like the text.
- Guides can hold YouTube and Twitch videos: paste a link and give it a title, and readers see a thumbnail that loads the player only when they press play.
