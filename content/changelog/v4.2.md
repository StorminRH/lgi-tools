## v4.2 — Codex

4.2 opens Codex, a field guide to wormhole space inside LGI.tools. Pilots write the advice, and the game data stays live.

### v4.2.0 — 2026-10-04

Codex has its first pages. Each guide opens at its own address with a contents list beside the text, and the Codex home lists every guide. Guides can hold headings, lists, quotes, tip boxes, tables, and links.

#### Added
- A Codex home that lists every guide.
- Guide pages with a breadcrumb, sections, and an "On this page" list.
- Every guide keeps its full edit history, and its text is shared under CC BY-SA 4.0.
- The site admin can start a new guide, edit one section or the whole page in place, and restore an earlier version from the page history. Readers never download the editor.
- The site admin can place live game data in a guide: a wormhole type, a site, a wormhole class, or any item, shown as an info box, a table, a value inside a sentence, or the site card. The numbers come from the game data and update when it does.
