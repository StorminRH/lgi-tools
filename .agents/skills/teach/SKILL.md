# Teach a concept

Explain at the user's level with a concrete example, the mechanism and its
consequence. Use a small visualization or interactive question when it
improves understanding. Keep established terms consistent.

Use `how` for an unresolved implementation question and `why` for an
unresolved rationale question. Reuse their applicable evidence; do not
chain both merely because this is teaching. Delegate noisy research under
the shared agent-call contract. State material uncertainty and cite the
source where a repository-specific claim depends on it.

Finish with the explanation the user asked for. Add practice only when the
user requests it or the task calls for learning through an exercise.
