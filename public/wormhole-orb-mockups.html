Wormhole ripple studies

Top-down water drop, not a spinning orb. Rings spread from the center and fade — strongest in the middle, more transparent as they reach the rim. Wisps travel outward on hover (or with the toggle). The core stays opaque enough to hold a class chip.

Hover also works. Reduced motion freezes the rings as two static bands.

1. CSS drop ripples

CSS Four rings scale from the core to the rim and fade out, staggered so it reads as a continuous drop. A radial mask keeps the inner rings louder than the edge. Hover wisps shoot away from center along fixed rays — no spin.

2. Packed CSS bands

CSS Same motion, more rings, slower. Closer to the in-game stack of concentric bands. Still expanding-and-fading, not rotating.

3. Canvas drop + outward wisps

Canvas 2D Rings are spawned at the core, grow, and lose alpha with radius. On hover, short wisps are emitted on random bearings and drift outward until they fade. Idle map still paints; the extra wisp spawn is hover-only.
